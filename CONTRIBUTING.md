# Contributing

The original application is MIT licensed. Contributions are expected under the same license, with third-party notices preserved. Please start with an issue describing a bug or proposed improvement; do not include private scripts, slides, recordings, credentials or screenshots containing personal material.

The app has no build step. Serve `web/` locally, change the relevant HTML, CSS or JavaScript, then run `node --test tests/*.test.mjs` and `node scripts/audit.mjs`. Keep dependencies self-hosted, maintain the privacy model and preserve third-party license files. Do not add analytics or external upload behavior without an explicit product and privacy review.

Check keyboard use, focus visibility, narrow screens and enlarged text. For recording changes, test countdown, cancel, pause/resume, stop, playback and download with synthetic media first, then clearly distinguish hardware checks from mocked tests. Update the verification notes with the checks actually performed.

For demo edits, use original or properly licensed assets, cite primary factual sources, and retain the independent educational disclaimer. Do not imply official endorsement.
